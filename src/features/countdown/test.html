WikiTree Browser Extension - Countdown Feature Test

These examples demonstrate how the countdown feature works. The countdowns will only be visible if you have the WikiTree Browser Extension installed and the countdown feature enabled.

Example 1: Sandy's 1776 Project - Beautiful Countdown (Recommended)

<span class="wbe-countdown">American Revolution • 250th Anniversary @ 2026-07-04</span>

Result:

American Revolution • 250th Anniversary @ 2026-07-04

Example 2: Advanced Format with Timezone and Custom Message

<span class="wbe-countdown">target=2026-07-04T00:00:00-04:00;label=American Revolution • 250th Anniversary;complete=Happy 250th Anniversary! 🇺🇸</span>

Result:

target=2026-07-04T00:00:00-04:00;label=American Revolution • 250th Anniversary;complete=Happy 250th Anniversary! 🇺🇸

Example 3: Short-term Countdown for Testing

<span class="wbe-countdown">Next Christmas @ 2025-12-25</span>

Result:

Next Christmas @ 2025-12-25

Example 4: Multiple countdowns

New Year: New Year 2026 @ 2026-01-01

Valentine's Day: Valentine's Day @ 2026-02-14

Example 5: Data attributes (still supported)

<span class="wbe-countdown" data-target="2026-07-04" data-label="Independence Day"></span>

Instructions for Sandy

For the 1776 Project page, simply paste this span where you want the countdown to appear:

<span class="wbe-countdown">American Revolution • 250th Anniversary @ 2026-07-04</span>

Features of the beautiful new design:

  • Professional appearance - gradient backgrounds, shadows, and animations
  • Large, readable numbers - easy to see the countdown at a glance
  • Responsive design - works perfectly on mobile and desktop
  • Graceful fallback - non-WBE users see readable text instead of nothing
  • Smooth animations - numbers animate when they change
  • Dark mode support - automatically adjusts for dark themes

Notes:

  • Only visible to users with WikiTree Browser Extension installed
  • Users without WBE will see nothing (the span will be empty)
  • Works on any WikiTree page: profiles, space pages, projects, G2G posts
  • Updates every second automatically
  • Handles timezones properly (the example uses Eastern Time)
